# Unity-Quaternion-GimbalLock-Demo
Unity交互式三维旋转演示项目，实时显示欧拉角与四元数(x,y,z,w)。

## 项目说明
本项目用于可视化欧拉角与四元数之间的转换关系。
在检视器中调整物体欧拉角，立方体同步旋转，并在屏幕右侧实时展示对应的四元数各分量：
- x,y,z：旋转轴
- w：cos(θ/2)，四元数中代表旋转角度的分量

> 可观察现象：物体旋转过程中，物体自身的局部坐标系会跟随物体一起旋转，而世界坐标系保持固定不变。

## 使用方法
1. 在Unity中打开场景
2. 进入运行模式(Play Mode)
3. 在检视器面板修改物体欧拉角
4. 在屏幕右侧实时观察欧拉角与四元数数值变化

## 备注
万向锁仅作为附加现象可观察，这次作业的核心目标是理解四元数分量与三维旋转的表达。
